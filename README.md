# 캐릭터 사진관 📸

레이어 파일(.psd · .clip)을 올리면 레이어를 파츠로 정리하고, 파츠를 골라 캐릭터 포트레이트를 찍어 저장할 수 있는 웹 도구입니다.

- 사이트: https://saturn97v.github.io/character-portrait-studio/
- 만든 사람: [@SATURN97v_](https://x.com/SATURN97v_)
- 해시태그: #캐릭터_사진관_찰칵

올린 파일은 서버로 전송되지 않고, 이용자의 브라우저 안에서만 처리됩니다.

## 저작권

- 이 저장소의 코드·디자인·이미지와 데모 캐릭터 '시범조교 양'의 저작권은 SATURN97v_에게 있습니다.
- 사이트 이용은 자유롭지만, 코드·이미지의 무단 복제·수정·재배포는 허용하지 않습니다.
- 제목 글꼴: 와구리체 (저작권 구리시, 무료 사용 가능 · 눈누 웹폰트 링크로 불러옴)
- 본문 글꼴: IBM Plex Sans KR (SIL Open Font License, Google Fonts로 불러옴)
